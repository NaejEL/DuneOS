- **(e) `evolutivite`** (`EVO-`) — **choices that block what comes next**: data structure modified without a replayable or reversible migration; third-party service called everywhere without an abstraction boundary; polling in a loop, unpaginated reads, missing indexes; hard-coded addresses, identifiers, thresholds instead of externalized ones; long or fallible processing in the request cycle; code assuming one user at a time where the domain guarantees the opposite.
