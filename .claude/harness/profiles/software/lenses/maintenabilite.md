- **(d) `maintenabilite`** (`MNT-`) — **inconsistencies between generation sessions**, first the **cross-cutting work, invisible file by file**: the same function written several times under different names; the same business rules in the interface and on the server with silent divergences; the same entity described differently on either side of the network. Then: contracts so broad they constrain nothing; abandoned leads; tests absent or whose assertions target the doubles; errors caught without handling; discontinuous style; comments that paraphrase the code.
