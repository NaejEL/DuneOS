## Phase 1 — Reconnaissance and mapping

1. **Arguments, git, resume**: write `$ARGUMENTS` as is to `.harness/runs/legacy-audit-arguments.txt`, then `K audit start --skill legacy-audit --arguments-file …` (AU-01 to AU-03: absolute `REPO`, `--categories` families among `hygiene`, `portabilite`, `qualite`, `filet` separated by `;`, `--max-specs` capped at `min(N, 25)` default 15; nonexistent path → stop, invalid option or value → exit 2). It opens the run in the repo, probes git (`git_absent` → LA-03: pre-finding of the hygiene family and **no git command afterwards**), reads the factory (LA-04 `factory`) and resumes `ROADMAP-legacy.md` if it exists (AU-09: `FAIT`/`EN_COURS` statuses preserved, numbering continued, `resumed`). It returns `run`, `auditors` (model and `pass_param` of the `audit.auditor` role), `validator`, `cap`, `allowed_writes`. Pass each subagent the `model` parameter when `pass_param` is true, never for `inherit`.
2. **Stack and bounds**: `K stack detect --root "<REPO>"` (markers, manifests, artefact folders, `sampled` beyond 2000 files: 3-level tree, 40 files read per auditor, sampling by largest / most recent / entry points). Read the manifests found.
3. **Map**: 2-3 level tree, stack and build commands, number of files, 15 largest files, README, LICENSE, `.gitignore`, CI, tests, `git_absent`, factory (absent: recommend `/software-factory`, non-blocking), resume, sampling.
