Exact frontmatter: `name: lab-run`; `description: Runs one cycle of the AI lab (Director + Neuro/Math experts → pre-registered protocol with human gate → Builder implements and runs → adversarial Verifier with correction loop → cross-interpretation → journal) on a research question, the keyword "suivant", or an approved protocol.`; `disable-model-invocation: true`; `argument-hint: "<research question | suivant | path of an approved protocol> [--models \"role=model;...\"]"`.

The body (imperative voice, real paths of the journal, the roadmap and the test command) writes `H` = `<PY> .claude/harness/harness.py` (copy of the core, Phase 4) and requires: **every launched sub-agent is recorded** with `H lab-run record --run <run> --agent <name> [--mode cadrage|interpretation] --duration-ms <ms> --tokens <n> --output .harness/runs/<x>.md` (output written as is with Write, never by the shell; `--dead` if the agent died; duration and tokens from the usage block, otherwise `H begin --run <run> --slot <agent>[:<mode>]` before the call; a missing measurement is logged as `null`, never blocking). The returned `action` field dictates what follows; never decide in place of the core. Flow:

0. **Entry** (LR-01, LR-02): write `$ARGUMENTS` with Write to `.harness/runs/lab-run-arguments.txt`, then `H lab-run start --arguments-file …`. The core strips `--models "role=model;…"` (aliases `math`, `neuro`, `builder`, `verifier`, `director.cadrage`, `director.interpretation`, `validator`; for this cycle only; unknown role or value → exit 2) and returns `mode` (`build`: a path under `experiments/` whose status line is `Status: PRE-REGISTERED` → step 3; `cadrage`), `models` and `run`. Pass each sub-agent the role's `model` parameter **when `pass_param` is true, never for `inherit`**. Announce the assignment in one line before the first spend.
1. **Framing**: `lab-director` in cadrage mode with the question; then **in parallel** (same message) `lab-neuro` and `lab-math` with the draft and their questions; then `lab-director` (cadrage) with the opinions for the **consolidated protocol** (it integrates or dismisses each remark, saying so). **A silent expert is not an agreeing expert** (LR-03): dead or unusable output → `relaunch` (once); then `continue` with the note "expertise <neuro|math> not collected": record it in the consolidated protocol and in the pre-registration gate, and leave open the questions addressed to that expert. A protocol without Math's opinion on statistical power or Neuro's on the fidelity of the analogue commits a campaign of runs to incomplete framing: the user must know before approving.
2. **Gates** (LR-04): `H gate decide/answer` with `lab-run.pi-questions` (option `Questions for the PI`: the questions for the PI), integrate the answers, write `experiments/EXP-<YYYY-MM-DD>-<slug>.md` with `Status: PROPOSED`, present the protocol, then `lab-run.preregistration` (`approval` / `iterate`: approve / iterate): approved → `Status: PRE-REGISTERED`, and **never modify Predictions or Abandonment criteria again**. **With no interaction possible, stop with an explicit error: a headless cycle requires the path of an already pre-registered protocol. Never measure without a pre-registered protocol.**
3. **Build & Run**: `lab-builder` (fresh context) with the protocol path; retrieve its raw report.
4. **Verify — 3 iterations maximum** (LR-05, LR-06): `lab-verifier` (blank context) with protocol and report, record its JSON block; `success` (APPROVED **and** `tests_passed`, `protocol_followed`, `rerun_consistent` true) → step 5; `fix` → `lab-builder` with the full list of `issues` (file, severity, kind, description), without regressing, affected runs re-executed, then a new Verifier; `relaunch` → relaunch a dead Builder or Verifier **once** without consuming an iteration; `fail` → fail explicitly, publish the remaining issues and write a journal entry "experiment invalidated — cause". **Never approve by exhaustion.**
5. **Cross-interpretation, once only, after approval** (LR-07): `lab-neuro` and `lab-math` in parallel (Math recomputes one key figure, Neuro confronts the curves with biology), then `lab-director` in interpretation mode: verdict, journal entry, table row, next experiment. Same silent-expert rule.
6. **Recording** (LR-08): gate `lab-run.consignation`; on `approval` (approval), **append** the entry to the detected journal (its exact order and format; create `docs/JOURNAL.md` if missing), the row to the roadmap table if there is one, protocol status → `DONE — <verdict>`; no other document (the architecture and frozen notes are never edited: mention in the report any decision to be recorded there). Headless: write the entry without a gate (the pre-registration was the authorization), marked `(recorded automatically — to be reviewed)`.
7. **Final report**: question, verdict, key figures vs pre-registered predictions, modified files (`git status`), tests, iterations, location of raw results, model assignment used (role → model, file or `--models`), next experiment (`/lab-run "<question>"` or `/lab-run suivant`); do not commit.

**Economy of the most expensive model.** A role assigned to a model other than `inherit` is a scarce resource: never pass it a whole document when an excerpt suffices (for `neuro` and `math`: the relevant protocol or report plus only the cited journal entries, never the full journal nor the raw results); never relaunch it for a cosmetic rewording; do not replay the interpretation at each iteration. The step 6 journal entry states in one line which model held which role: a condition for reproducibility of the judgement, like seeds.
