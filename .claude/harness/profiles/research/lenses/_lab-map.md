## Phase 1 — Reconnaissance and corpus mapping

1. **Arguments, lab, resume**: write `$ARGUMENTS` as is to `.harness/runs/ai-lab-audit-arguments.txt`, then `K audit start --skill ai-lab-audit --arguments-file …` (AU-01 to AU-03, AA-01 to AA-03: absolute `REPO`; `--lenses` among `fidelite`, `validite`, `fuites`, `bio`, `route` separated by `;`; `--max-questions` bounded to `min(N, 12)` default 6; `--models` for this audit only, roles `neuro`, `math`, `director.cadrage`, `validator`, unknown value or role → exit 2). It returns `run`, `lab` (AA-05: agents and `lab-run` present), `factory`, for each auditor `subagent_type` (`lab-math`, `lab-neuro`, `lab-director`, or `Explore` without a lab: then recommend `/ai-lab`, non-blocking), `model` and `pass_param` (AA-06: `math` for fidelite/validite/fuites, `neuro` for bio, `director.cadrage` for route, `validator` for validators), and the resume of an existing `AUDIT-lab.md`. If the project has **no biological inspiration** (judgement, after reading the corpus in step 2, which may precede `audit start`: `REPO` = first token without `--`, otherwise the current directory), run `audit start` with `--lenses` without `bio` and say so in the report. Pass the `model` parameter to each sub-agent when `pass_param` is true, never for `inherit`; announce the assignment in one line before the first spend. An expensive role receives the map and its lens, never the whole journal.
2. **Stack and corpus**: `K stack detect --root "<REPO>"`, then read `CLAUDE.md`, `README.md` and `docs/` for the exact paths of the **experiment journal** (and the format of its entries), the **architecture document**, the **roadmap**, the **frozen documents**, the **vision**, the **config class**, the **eval scripts** (question, metric, control, `argparse` options), the **vocabulary**, the **current state**, the **non-negotiable constraints** and the **references**. Documented test command noted, run only if it is CPU and without downloads (a failure is a `FID-` finding).
3. **Bounds**: `K stack journal --file <journal>` (ST-05): beyond 1500 lines (`sampled`), `validite` and `route` receive the last 15 entries plus the results table; mark the audit "sampled".
4. **Resume**: for each already retained question, look in the journal for an entry **later** than the date of the audit that settled it: `K audit settle --audit-date <YYYY-MM-DD> --entry-date <YYYY-MM-DD>` returns `TRANCHEE (journal <date>)` (AA-10) or `null`.

Produce the **map**: stack, declared hardware, corpus paths with number of journal entries and date of the last, evals and metrics, roadmap mechanisms and their status, constraints, references, `lab`, `factory`, resume, sampling.
